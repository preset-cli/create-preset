# Examples

Nearly identical templates need the same fix in several places. Common skills get copied into every project. A starter inside a monorepo needs its files and dependencies cleaned up before it can stand alone.

These examples show how to describe those steps in a preset. Each includes source files, a JSON config, and the resulting files.

<ExampleList />

## Reading an example

Start with the source, inspect the preset, then compare the output. Some examples offer multiple editions generated from the same source.

Repository URLs are fictional and code is simplified to focus on file operations. Config fields and commands match the CLI. Replace repository URLs and provide the corresponding source files before running. If a template author already supplies a command, use it directly.

See [Getting Started](/guide/getting-started) for prerequisites and [Preset Configs](/guide/preset-configs) for the full reference. Real projects are listed in the [showcase](/showcase).
