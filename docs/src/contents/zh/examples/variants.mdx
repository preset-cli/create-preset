# 同一模板，生成不同版本

基础版不需要统计模块，团队版需要保留。其他代码相同，修复问题时却要同时修改两份模板。

保留一份完整源码，用两份 Preset 描述差异。基础版移除统计模块及入口引用，团队版保留，生成的项目仍然各自独立。

## 看看发生了什么

- 两份配置的 `source` 相同，都读取仓库中的 `starter` 目录。
- 基础版用 `exclude` 排除 `src/analytics.ts`，再用 `replace` 删除入口中的导入和调用。
- 团队版保留完整源码。切换版本后，查看「生成结果」中的 `src/main.ts`。
- `package.json` 的 `name` 会按目标目录更新。

公共代码在源仓库中维护一份，生成时应用各版本的差异。已经生成的项目不会随后自动同步。

`replace` 按原文精确匹配。源码改动后，如果旧文本不再存在，创建会报错，需要一起更新配置。这个示例适合少量、明确的文件差异；CLI 不会自动分析模块引用或转换 TypeScript。

完整操作说明见[Preset 配置](/zh/guide/preset-configs)。
