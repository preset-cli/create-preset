# 创建时调整文件和配置

服务模板中的演示文件、README 和默认配置通常需要在创建项目后调整。示例将这些固定操作写入 Preset，在创建时删除 `demo.js`、重写 README、替换环境变量，并移除 `package.json` 中的演示命令。

<ExampleExplorer example="file-changes" locale="zh" />

## 文件处理顺序

1. `exclude`：复制时跳过 `demo.js`，新项目里就不会有这个文件。
2. `write`：重写 `README.md`，`lines` 中的每一项对应文件中的一行。
3. `replace`：把 `.env.example` 中的 `APP_LABEL=Starter` 换成 `APP_LABEL=Team`。
4. `json`：修改 `package.json`，把 `scripts.demo` 设为 `null` 就能删掉这条命令，`scripts.start` 会保留。

## 预览创建计划

配置保存为 `presets/service.json` 后，可以加上 `--dry-run` 查看准备执行的操作：

```bash
pnpm create preset init my-service --from ./presets/service.json --dry-run
```

这一步不会下载仓库，因此也不会检查 `replace` 中的原文能否找到。确认计划后，去掉 `--dry-run` 创建项目，再检查生成的文件。

其他字段的用法见[Preset 配置](/zh/guide/preset-configs)。
