# 使用示例

模板只差几处，却要维护多份；常用 Skills 换个项目又要复制一遍；monorepo 里的子项目，取出来之后还得整理文件和依赖。

下面的示例分别演示这些步骤如何放进 Preset。每篇都有源文件、JSON 配置和生成结果，可以切换文件查看差异。

<ExampleList locale="zh" />

## 如何阅读示例

先看源文件，再看 Preset 修改了什么，最后对照生成结果。部分示例可以切换版本，比较同一份源码的不同输出。

示例使用虚构仓库和简化代码，重点是目录和文件处理方式。配置字段和命令与 CLI 一致；实际使用时，需要替换仓库地址，并保证仓库中存在对应文件。模板作者已提供命令时，直接使用即可。

运行环境见[快速开始](/zh/guide/getting-started)，完整字段见[Preset 配置](/zh/guide/preset-configs)。真实项目的使用情况见[案例展示](/zh/showcase)。
